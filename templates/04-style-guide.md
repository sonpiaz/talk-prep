## Layout patterns used

Mark which ones appear in this deck.

- [ ] **Title hero** — full-bleed image, title + subtitle bottom-left with dark gradient scrim.
- [ ] **Photo full-bleed** — photo fills frame, optional caption bottom.
- [ ] **Stat big number** — one giant number (`--accent` color), one-line caption.
- [ ] **Compare row** — two or three columns, same structure in each.
- [ ] **Quote dark** — large italic quote + attribution, photo right 50%.
- [ ] **Grid 2×2** — four tiles, photo or stat in each.
- [ ] **Statement only** — typography only, no image.
- [ ] **Handwritten accent** — speaker's handwriting overlay on photo (scanned asset).
