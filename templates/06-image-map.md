## Intent tags recognized by gen-images.ts

Add a tag at the END of the prompt (e.g., `[cinematic_photo]`) to route to the right model.

- `[cinematic_photo]` — FLUX 1.1 Pro Ultra (Kinfolk vibe).
- `[vietnamese_text_in_image]` — Ideogram V3 (for packaging, signage with Vietnamese diacritics).
- `[logo_wordmark]` — Ideogram V3 (logo/wordmark generation).
- `[flat_illustration]` — Recraft V3.

If no tag, script defaults to `cinematic_photo`.
